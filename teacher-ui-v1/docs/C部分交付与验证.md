## 实际验证

- `npm run build`：通过 TypeScript 和 Vite 生产构建。拆分图表包，主入口约 227 kB（gzip 约 74 kB），图表路由按需加载。
- `npm run docs:validate`：候选 OpenAPI 3.0.3 结构与引用校验通过。
- `npm test`：11 / 11 通过。
- 最后高风险草稿筛选修正后：`npm test -- tests/errors.spec.ts` 2 / 2 通过，并重新构建成功。其余未受影响用例不重复执行。
- 依赖安装审计：0 项已知漏洞（2026-11-08 安装结果）。
- 截图人工检查：桌面总览、工单详情、390px 手机页面；图表正常、无明显遮挡。360 / 390 / 1440 的总览、列表、详情、洞察均验证无页面横向溢出、无未捕获 JS 异常。

覆盖：审核→分派→催办→备注→刷新持久化；风险/搜索/分页；父子拆分与深链；部门驳回重新分派；提醒不改变状态；归档权限；400/401/403/404/409/500 场景；并发审核冲突后刷新权限并保留输入；退回原因必填；高风险草稿仍可从高风险统计卡找到。
