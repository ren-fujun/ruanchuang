以上结论限于具体请求与合成账户关系；不应推广为未覆盖端点或生产部署的安全保证。

### 待确认：AI Agent 通用接口的角色/数据边界

- **位置：** `server/index.js:465-477`
- **触发条件：** 任意已登录角色请求 `/api/ai/agents/:name`。代码对 `attribution` 单独要求 counselor；其他 agent 统一将请求体作为 payload 传入。非 `attribution` 分支尚未在本次请求集逐 agent 验证其接受字段、可读数据和输出是否会暴露敏感信息。
- **影响：** 目前证据不足以判定越权或敏感信息泄漏，列为未验证风险而非已确认漏洞。
- **建议：** 明确每个 agent 的允许角色、输入 schema 和可用数据范围；仅从服务端按用户权限构造敏感数据 payload。
- **验证限制：** 按父代理要求，本次未继续扩展 Agent 接口探测；没有调用外部模型。
