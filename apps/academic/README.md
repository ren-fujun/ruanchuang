# 教务处端

独立入口：`npm run dev:academic`，默认端口 5193；独立构建：`npm run build:academic`。

当前可使用已配置学生范围的教务账号登录，粘贴小批 CSV，由服务器校验预览；确认后保存为名单批次，再由教务人员手动分发到 B 的学业任务。CSV 表头须依次为 `studentId,course,mentorId,counselorId`。页面和后端均以服务端角色及授权范围为准，预览不是保存，保存不是分发。

试用账号若要求首次改密，页面提供改密表单。尚未分发的最新批次可重新校验并保存为更正版本，旧版本保留且不可分发。已授权的学业事项可在页面回写正式结果与来源。当前没有账号开户页面，缺失范围配置会拒绝名单操作。批次分发后的更正、CSV 文件直接上传和正式教务系统对接尚未完成；请使用虚构测试数据。
