## 反向代理要求

- `/api/*` 转发到 API 服务。
- 五个端分别托管自己的静态产物。
- SPA 路由刷新回退到对应端的 `index.html`。
- 所有入口使用 HTTPS，禁止浏览器混用 HTTP API。
- 请求体大小、上传目录和 CORS 白名单按生产环境配置。
- 参考 `deploy/nginx.conf.example`，使用独立子域避免五端静态资源路径互相覆盖。

## 数据备份

发布候选固定后先执行：

```powershell
node scripts/ops/backup.mjs
```

首次邀请前按以下顺序演练一次：

1. 停止 API。
2. 使用临时副本执行恢复。
3. 重启 API。
4. 检查账号、报修、异议和终态数据数量。
5. 恢复失败时保留原数据并停止发布。

## 回退

- 代码回退到发布候选提交号，不回退整个不可追踪目录。
- 数据回退使用恢复前自动保存的 `.pre-restore-*` 文件。
- 记录回退原因、操作人、时间和恢复文件。
- 权限泄露、数据丢失或核心链阻断时暂停对应试用。
