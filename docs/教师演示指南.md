## 明天启动

在仓库根目录打开终端：

```powershell
git switch feat/counselor-neo-ui
git pull --ff-only
npm ci
npm run demo
```

依赖已经装好时可以直接执行 `npm run demo`。首次安装依赖需要网络，建议今天完成。打开 http://127.0.0.1:18792 ，终端保持运行。

该命令构建页面并启动单个本地服务，使用独立的 `.tmp/teacher-demo/store.json`，不会污染原 `server/data/store.json`。默认使用本地规则、GraphRAG 和风险筛查，不依赖云模型密钥或现场网络。端口占用时先停止上一次演示服务，或设置 `$env:PORT='18793'` 后重新运行。

用普通浏览器窗口登录学生，再用 InPrivate/无痕窗口登录辅导员，避免两个标签共用登录态。可直接点“学生视角”“辅导员视角”。账号也可用 `20230118 / 123456` 与 `chenyuan / 123456`。

## 5 分钟演示顺序

1. **30 秒介绍**：学生统一提交，AI 提供分类、风险和部门建议，辅导员负责复核与跨部门协同。
2. **1 分钟学生提交**：进入“新建诉求”，输入“宿舍洗手台水龙头一直漏水，已经漏到柜子里了，物业电话打不通，希望今天尽快上门处理。”，填写地点，点击“让 AI 先看看”，展示建议部门、摘要和风险，再确认提交。若显示自助指引可选“仍要提交”。
3. **1 分钟辅导员审核**：刷新工作概览，打开最新待审核工单，展示 AI 研判与时间线；“审核并分派”→“一键采纳”→“确认分派”。
4. **1 分钟协同闭环**：“记录部门接单”→“确认接单”；“录入处置结果”，填写“维修人员已更换水龙头，现场复查无渗漏。”→“完成并通知学生”。
5. **1 分钟学生评价**：回到学生窗口刷新详情，“确认办结”→“确认办结并评价”，展示工单归档。回到辅导员窗口刷新，展示统计变化。
6. **剩余时间**：展示低饱和桌面工作台、手机适配、协同洞察或宿舍查寝。可以补充“云模型不可用时本地链路仍能处理，AI 结论需要人工复核”。

跨窗口进度需要刷新；当前没有 WebSocket 实时推送。不要把原型描述为已经接入真实学校业务、短信或部门系统。
