## 1. 接口合同

### 1.1 统一约定

| 项目 | 约定 | 强制程度 |
| --- | --- | --- |
| 协议 | HTTP/HTTPS，JSON | 必须 |
| API 前缀 | `/api` | 必须 |
| 请求 Content-Type | `application/json; charset=utf-8` | 必须 |
| 字段命名 | **camelCase**，全项目统一；禁止 `snake_case` | 必须 |
| URL 命名 | 资源名复数、全小写、连字符；禁止动词堆叠 | 必须 |
| 成功响应 | `{ "code": 0, "msg": "ok", "data": { ... } }` | 必须 |
| 错误响应 | `{ "code": 40001, "msg": "可展示给用户的中文说明", "data": null }` | 必须 |
| 鉴权 | `Authorization: Bearer <token>`；登录/演示/健康检查除外 | 必须 |
| Token 有效期 | 不透明字符串，服务端至少保留 12 小时；失效返回 401 | 必须 |
| 角色 | `student` / `counselor`，由后端根据 token 判定，不信任前端传 role | 必须 |
| HTTP 状态码 | 成功 200/201；错误使用对应 4xx/5xx；不得全部返回 200 | 必须 |
| 日期时间 | UTC ISO 8601，毫秒可选，统一 `2026-11-07T12:30:00.000Z`；前端按 Asia/Shanghai 展示 | 必须 |
| 纯日期 | `YYYY-MM-DD`，如知识库 `updatedAt`、周报 `week[].date` | 必须 |
| 空值 | 对象/标量缺失用 `null`；列表为空用 `[]`；禁止 `undefined`；用户主动留空的文本用 `""` | 必须 |
| 分页参数 | `page` 从 1 开始，默认 `1`；`pageSize` 默认 `20`，最大 `50` | 必须 |
| 分页响应 | `data` 内包含 `page`、`pageSize`、`total`、`hasMore` | 必须 |
| 排序 | 由后端确定并写入合同，不由前端猜测 | 必须 |
| 时间基准 | 服务端统一以 UTC 计算 SLA，`dueAt` 为绝对时间 | 必须 |
| CORS | 开发允许 `http://127.0.0.1:5180`、`http://localhost:5180`、`http://127.0.0.1:8787`；生产同源；不得使用 `*` | 必须 |

### 1.2 错误码表

| HTTP | code | 业务含义 | 前端处理 |
| --- | --- | --- | --- |
| 200/201 | `0` | 成功 | 取 `data`，不读其它字段 |
| 400 | `40001` | 参数缺失、类型错误、枚举非法、分页非法 | 表单字段标红或 Toast；不跳登录；保留用户输入 |
| 401 | `40101` | 未登录、Token 缺失/过期/无效 | 清除 `zhihui_token`，跳 `/login`，Toast “登录已失效” |
| 401 | `40102` | 登录账号或密码错误 | 留在登录页，表单内标红错误；不清 token、不跳转 |
| 403 | `40301` | 角色无权限；学生访问他人工单；学生调用辅导员接口 | Toast “无权访问”；返回上一页；**不清 token** |
| 404 | `40401` | 工单、通知、知识条目不存在 | 展示空状态或“已归档”；提供返回列表 |
| 409 | `40901` | 当前状态不允许该操作；重复审核、重复确认、重复拆分 | 刷新详情，Toast 后端 `msg`；不盲目重试 |
| 413 | `41301` | 请求体过大（附件元数据超限） | 提示压缩/减少附件；保留表单 |
| 500 | `50001` | 未捕获的服务端错误 | Toast “服务暂不可用，请稍后重试”；记录接口与时间；不展示堆栈 |

**规则：**

1. HTTP 状态码和 `code` 必须同时正确，不允许 HTTP 200 包错误。
2. `msg` 必须是可直接展示的中文，不得出现 `Error: ...`、堆栈、SQL、文件路径。
3. `data` 在错误时固定为 `null`。
4. 前端只根据 `code`/HTTP 做逻辑分支，不解析 `msg` 文本。
5. `40101` 统一由 `src/lib/api.ts` 触发 `zhihui:auth-expired`，页面不各自处理；`40102` 只用于登录页表单错误，不触发全局登出。

```ts
const API_BASE = import.meta.env.VITE_API_BASE_URL || '/api'

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const token = localStorage.getItem('zhihui_token')
  const headers = new Headers(init?.headers)
  headers.set('Content-Type', 'application/json')
  if (token) headers.set('Authorization', `Bearer ${token}`)

  const response = await fetch(`${API_BASE}${path}`, { ...init, headers })
  const body = await response.json()

  if (!response.ok || body.code !== 0) {
    if (body.code === 40101) window.dispatchEvent(new CustomEvent('zhihui:auth-expired'))
    throw new ApiError(body.msg, body.code, response.status)
  }

  return body.data as T
}
```

## 5. 风险与变更流程

### 5.1 接口字段 / 结构变更流程

**任何字段、路径、枚举、错误码变更，按以下顺序执行：**

1. **提出人**在 `docs/change-log.md` 新增一行：日期、版本、接口、字段、旧值、新值、原因、影响端。
2. **A（后端）**在 2 小时内更新：
   - 本文件对应章节；
   - `docs/openapi.yaml`；
   - `src/types.ts`；
   - 后端实现（如已实现）。
3. **D**同步更新 MSW fixture 与 E2E 断言。
4. **B/C**在自己的分支适配，PR 描述引用变更记录。
5. **A + B/C** 至少一方在 PR 中确认“字段已对齐”；涉及破坏性变更时 A、B、C 三方确认。
6. 合并后由 A 在群里发变更通知，格式固定：

```text
[合同变更] v1.1 / 2026-11-11 14:00
接口：GET /api/student/home
字段：aiTip -> aiHint
旧值：string
新值：string
影响端：学生端
迁移截止：2026-11-11 18:00
负责人：A（后端）/ B（前端）
```

**冻结规则：**

- 2026-11-12 18:00 后不再接受破坏性变更。
- 2026-11-13 14:00 后只接受**新增可选字段**，且必须有默认值；不得改已有字段名/类型/枚举。
- 演示当天不接受任何合同变更。

**禁止：**

- 后端先改、前端不知道；
- 前端在本地改字段名但不改合同；
- 在 `src/types.ts` 之外复制一套接口类型；
- 用 `any` 掩盖字段不一致；
- 为了演示临时改接口但不记录。
