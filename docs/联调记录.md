
脚本退出码为 `0` 表示全部通过；生成的 `docs/smoke-latest.md` 用于回填本记录。

## 通过标准

### 1. 健康检查

- HTTP 状态码 `200`
- `code=0`
- `data.ok=true`
- `data.service` 非空
- `data.time` 为 UTC ISO 时间

### 2. 登录

- 学生：`data.token` 非空，`data.user.role="student"`
- 辅导员：`data.token` 非空，`data.user.role="counselor"`
- 错误结构统一为 `{ code, msg, data: null }`

### 3. 工单列表

- `data.tickets` 是数组，`data.counts` 是对象
- `page=1`、`pageSize=20`、`total`、`hasMore` 均存在
- 学生返回的每条工单都满足 `ticket.studentId === 当前学生 user.id`
- 辅导员使用同接口时能获取全量工单
