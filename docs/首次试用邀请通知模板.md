# 首次试用邀请通知模板

> 本系统为邀请制测试环境，仅用于虚构事务体验，不是学校正式办理入口。请不要录入真实敏感信息。账号密码请通过单独渠道发送，不要写入群公告、二维码或公开文档。

## 邀请内容

- 试用时间：
- 预计耗时：10—15 分钟
- 学生端 H5：
- 辅导员端：
- 备用 H5：
- 反馈入口：页面顶部“试用反馈”
- 反馈截止时间：

## 学生任务

1. 使用分配的账号首次登录并修改初始密码。
2. 提交一条虚构宿舍报修。
3. 查看报修进度，体验满意或一次异议反馈。
4. 提交页面反馈，说明最卡的一步。

## 辅导员任务

1. 使用分配账号登录并修改初始密码。
2. 查看报修监督、一次异议和待协调记录。
3. 查看本科请假审批与学业协商待办。
4. 提交页面反馈，说明信息是否足够支持处理。

## 账号发放

账号和初始密码由管理员分别发送，不进入公开仓库。首次登录必须改密。邀请名单只记录试用编号、角色和账号，不记录密码。

## 故障处理

- 页面打不开：改用备用 H5。
- 登录失败：让用户核对账号并联系管理员重置，不在群内发送密码。
- 数据提交失败：记录时间、页面、操作和页面提示，不重复提交。
- 核心权限或数据异常：暂停该用户试用并立即通知负责人。
