# 协同建议：简化版

本版本基于现有 v1 工单流程，将诉求中的设施、地点和安全关键词用于生成待核实的部门建议，并在辅导员工单详情中显示依据和可能需要补充的信息。图书馆设施问题可以同时建议图书馆与后勤；安全关键词会增加保卫部门建议。辅导员仍需结合原文确认、修改和分派。

这是一套示例规则，不是学校已确认的部门权责或 SLA，也不能识别所有复合问题。信息缺失提示使用简单规则，可能有误报和漏报；风险提示不是诊断，不替代人工核查。部门建议和回复草稿不表示已经联系任何部门。可选大模型只增强部分文本字段，部门建议保留规则结果；模型无法使用时回退本地规则。

本次不新增工单状态，不接入真实校园部门系统，不宣称实现多智能体、GraphRAG、风险诊断或趋势预测。既有演示数据、联系方式和知识库内容需由学校核验后才能用于真实场景。历史工单没有新字段时，页面显示人工核实提示。
