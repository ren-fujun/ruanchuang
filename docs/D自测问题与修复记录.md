# D 自测问题与修复记录

日期：2026-11-25。范围为本地真实浏览器和 API 自测，不包含尚未部署的公网环境。

## 问题 1：反馈缺少试用统计字段

- 现象：反馈表只采集类型、评分和描述，无法直接得到任务是否完成与耗时。
- 修复：增加“任务是否完成（已完成/部分完成/未完成）”和“完成耗时（1—240 分钟）”。
- 服务端：校验并持久化 `taskCompleted`、`durationMinutes`，管理员反馈列表可读取。
- 验证：`node scripts/c/feedback-e2e.mjs` 和 `server/trial-auth-api.test.js` 通过。

## 问题 2：非试用模式显示无效反馈按钮

- 现象：本地非试用环境仍显示“试用反馈”，提交后返回“试用反馈未启用”。
- 修复：新增 `GET /api/trial/status`，前端仅在试用功能启用时显示入口。
- 验证：非试用演示彩排不再出现无效反馈入口；试用模式五端反馈 E2E 仍通过。

## 问题 3：导师/教务端反馈状态权限错误

- 现象：导师和教务会话请求 `/api/trial/status` 被角色中间件拦截，导致反馈入口不显示。
- 修复：将该只读状态接口加入导师/教务允许路径。
- 验证：五端反馈 E2E 中五个角色全部通过。

## 问题 4：测试随机端口偶发失败

- 现象：自动测试偶尔分配到浏览器禁止端口 `2049`，导致页面无法打开。
- 修复：测试动态端口限制为 `10000` 以上。
- 验证：C 报修、反馈、五端、D 后勤和演示彩排脚本均重新运行通过。
