# 一日冲刺实现与验收状态

本地开发草稿，未经团队合并或服务器部署。预约采用模拟数据和试行规则，不能用于真实学生业务。

## 已实现

- 辅导员发布按五分钟对齐的接待窗口；关联学生提交事项与可编辑时长，同一请求标识防重复。
- 辅导员对单个窗口触发排班，待排申请按创建时间排序，已有候补优先；占用的时间不重排，排不下进入候补。取消已确认预约后尝试按序补位。
- 双方可在预约中留言；查看留言时标记已读。预约列表提供未读数（刷新后更新）。
- 预约时长规则建议；可选启用外部模型 `APPOINTMENT_ADVICE_LLM=true`，异常或格式不合规则回退，学生自行修改。

## 尚未达到计划

- 每次申请目前选择一个完整开放窗口，不支持两个意向窗口或个人课表冲突；无老师确认的期限优先级、人工调整或持久通知。
- 留言未做实时推送；未验证手机视图和跨进程、多实例并发。当前 JSON 数据存储仅作为演示，不适合生产环境。
- 未取得辅导员访谈、真实同学体验、视频录制、旧新版可比测试；不能声称已经试用或效率提升。
- AI 12 条固定虚构案例仅测规则，不是人工一致率或实际准确率；直接模型和检索对照、真实模型费用、Token、缓存及重试成本均未测。
- 真实接口跨端、原有报修请假及学业全链回归待完成；本环境对本机 TCP 连接返回 EACCES，隔离 API 评测和 B 试用脚本未能运行。
