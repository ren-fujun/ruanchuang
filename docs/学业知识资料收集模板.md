# 学业知识资料收集模板

本模板用于收集资料，不会自动写入系统或发布。每份文件复制一份填写；请以学校实际资料为准，不填写虚构规定。

- 文件名称：
- 发布部门：
- 原始链接或文件位置：
- 发布时间／版本号：
- 适用对象（本科生、研究生、学院、年级等）：
- 生效时间与有效期：
- 是否已确认仍然有效：
- 建议关键词（每个2—30字）：
- 可公开给学生的范围：
- 文件原文（可按章节分段）：
- 审核人及核对日期：

资料收集后，辅导员可在知识纠错页面粘贴正文生成草稿，补充关键词、核实来源，并由另一位有权限的人员审核发布。扫描件先人工核对识别文本。学生咨询仅检索已发布且未过期的条目；检索无法匹配时不会凭空生成学校政策。
