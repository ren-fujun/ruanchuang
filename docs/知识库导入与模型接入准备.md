# 知识库导入与模型接入准备

辅导员知识纠错页面可粘贴文件正文生成草稿。接口 `POST /api/b/knowledge/import-text` 接收 `title`、`source`、`department`、`validUntil`、`text`。正文按空行分段，最多20段、总计20000字、单段4000字；每段原文生成一个草稿。当前不支持文件上传，不解析 Word/PDF、不调用大模型。不要向外部模型或仓库提交真实学生数据。

导入草稿没有关键词，不能发布或被学生检索。作者需使用已有 `POST /api/b/knowledge`，带草稿 `parentId`，为新版本补充答案和关键词；另一位有审核权限的辅导员通过已有 review 接口审核发布。只有已发布且未过期条目能被学生咨询检索。来源和原文应经审核人员对照原文件检查。

项目默认不预置或发布学校政策；真实文件由团队自行收集并核实，可使用《学业知识资料收集模板》。测试示例仅用于本地隔离环境：标题“虚构学业说明”，来源“虚构测试文件”，部门“测试部门”，有效期“2099-01-01”，正文“【虚构示例】学生应向测试部门询问后续安排。本段不是学校真实规定。” 不要当成真实校规发布。

校级、院级基础资料由项目团队核对来源、版本、适用范围与原文后，维护在 `server/b/official-knowledge.json`。默认空数组，不需要辅导员逐条审核；发布代码和重启服务后可供学生检索。每条包含 id、title、answer、sourceExcerpt、department、source（HTTPS原始网址）、keywords（2至30字）及 validUntil。系统校验结构，不会自动验证网址是否属于学校、文件是否真实或仍有效；由项目团队负责。过期条目不会检索。维护此文件需保留原文和来源，并及时更新旧版本。

学生咨询在匹配到有效条目后，可以调用配置好的模型基于资料组织回答并显示原文。模型未配置或调用失败时返回已有答案；未找到可靠资料时引导继续咨询或人工处理。规则护栏只能拦截部分风险，不能保证语义正确，仍需结合原文测试。校内模型切换时需要验证接口兼容和回答质量。当前未实现文件上传、文档解析或向量检索。
