# 知识库导入与模型接入准备

辅导员知识纠错页面可粘贴文件正文生成草稿。接口 `POST /api/b/knowledge/import-text` 接收 `title`、`source`、`department`、`validUntil`、`text`。正文按空行分段，最多20段、总计20000字、单段4000字；每段原文生成一个草稿。当前不支持文件上传，不解析 Word/PDF、不调用大模型。不要向外部模型或仓库提交真实学生数据。

导入草稿没有关键词，不能发布或被学生检索。作者需使用已有 `POST /api/b/knowledge`，带草稿 `parentId`，为新版本补充答案和关键词；另一位有审核权限的辅导员通过已有 review 接口审核发布。只有已发布且未过期条目能被学生咨询检索。来源和原文应经审核人员对照原文件检查。

测试示例仅用于本地隔离环境：标题“虚构学业说明”，来源“虚构测试文件”，部门“测试部门”，有效期“2099-01-01”，正文“【虚构示例】学生应向测试部门询问后续安排。本段不是学校真实规定。” 不要当成真实校规发布。

后续模型接入：在检索后通过可配置的服务端适配器发送经授权的相关片段，输出同时保留来源与原文；模型未配置、超时或无可靠依据时转人工。待确认供应商、授权和密钥后才接入真实外部服务。切换校内模型时仍需验证接口兼容和输出质量。当前未实现文件上传、文档解析、向量检索或模型回答。
