# 试用登录接口开发说明

仅供隔离环境联调，尚未满足对外试用或生产部署条件。设置 TRIAL_MODE=true 后，演示直登被禁用，明文密码账号和旧演示会话不能用于登录；仅接受服务端保存的 scrypt 密码哈希，账号可通过 disabled 与 expiresAt 禁用或设定有效期。试用会话有效期为八小时。

试用用户若由可信管理者设置 mustChangePassword=true，可以登录并调用 /api/me、/api/auth/change-password、/api/auth/logout；其他需要登录的接口会拒绝，直到通过 change-password 提供 currentPassword 与至少10位的新密码。修改成功后旧密码失效，其他会话被撤销。密码哈希不会通过 publicUser 返回。

失败次数限制仅为单进程内的 IP 限流：10次失败后在15分钟内拒绝，服务重启后清空，不能替代正式的共享限流、代理配置、监控或反滥用方案。默认不是试用模式；未设置时原演示账号仍可用。

学生、辅导员、教务、后勤和导师页面均支持首次改密；`node scripts/e2e/trial-password-ui.mjs` 使用隔离账号验证五端流程。

仍待完成：服务器和HTTPS、正式会话与密钥管理、可靠存储/备份，以及逐端权限审计。不得以本模块通过测试为由对外开放试用或接入真实学生数据。

## 管理员接口的当前范围

仅 TRIAL_MODE=true 且已由可信方式配置 trialAdmin=true 的账号可调用。POST /api/trial/admin/accounts 可一次创建1至50个账号，须提供未来到期时间和至少10字符的初始密码；服务器只保存哈希，账号首次登录须改密。学生、辅导员、教务、导师和后勤可配置各自允许的范围字段，关联对象必须存在并有效。请求不允许自行赋予 trialAdmin。

POST /api/trial/admin/accounts/:id/reset-password 重置初始密码并使该账号原会话失效；POST /api/trial/admin/accounts/:id/status 传 disabled 布尔值，停用时撤销已有会话。操作仅记录人员编号、操作者、动作与时间，不记录初始密码。管理员账号本身不允许通过这两个接口操作。

学生和辅导员在批量创建时若填写关联，必须双方对应一致。对于已有账号，管理员可调用 POST /api/trial/admin/accounts/:学生编号/relations，完整提交 educationLevel（undergraduate 或 postgraduate）、counselorIds 和 classAdvisorIds（数组，可为空）。服务先校验全部账号及班导师资格，再同时更新学生的审批人和辅导员负责学生列表；无效请求不会修改关系。变更将影响现有请假及学业事项的访问范围，操作前需核对实际分工。

GET /api/trial/admin/accounts 支持管理员分页检查账号和人员范围，使用 offset 和 limit（1 至 100），响应不包含密码或哈希。尚未提供管理员开户页面、授权关系修改界面或安全的首个管理员初始化工具；只可在隔离测试环境由可信人员配置虚构账号。上线前需完成 HTTPS、管理员身份托管、接口审计、密码安全发放及持久化故障处理；不得发送真实密码到聊天、日志或团队仓库。
