# 智汇中枢首次试用演示脚本

本脚本使用虚构事务，不出现真实学生姓名、电话、心理记录或学校未确认的制度。账号和密码私下发放，不写入本文件、二维码或群公告。

## 演示前检查

- 五端 HTTPS 地址可访问，证书有效。
- 学生端手机浏览器宽度 390px 可用，辅导员端 1366×768 和 1440×900 可用。
- 演示账号均已完成首次改密。
- 演示数据已加载，看板不为空。
- 高风险与逾期工单各至少一条。
- H5 备用入口已打开并单独保留登录状态。
- 反馈入口可提交，管理员可读取反馈。

## 学生视角 3 分钟

1. 学生登录后进入首页，说明页面顶部“试用测试系统，非学校正式办理入口”。
2. 点击“宿舍报修”，选择“水电”，填写虚构地点和故障描述。
3. 提交后进入报修详情，说明报修直达后勤，不需要辅导员先审核。
4. 打开“AI 问答”，询问“宿舍漏水应该找谁”，展示回答或人工转介。
5. 返回“正在跟进/报修记录”，说明学生可查看处理结果并选择满意或提交一次异议。

## 辅导员视角 5 分钟

1. 登录后展示首页：待审核、在办、逾期、高风险和重点待办。
2. 打开“报修监督”，筛选待学生反馈、异议待回应和异议超时。
3. 打开一条学生异议，展示处置结果、学生异议、后勤回应、提醒和协调结案入口。
4. 打开“请假审批”，展示本科辅导员审批路径；不要冒用研究生班导师权限。
5. 打开“学业跟进”，展示导师和辅导员协商承担行动、变更历史和必要的隐私边界。
6. 最后进入“协同洞察”，展示服务端统计，不承诺实时风险预测或无人干预处置。

## 管理/评审视角 2 分钟

1. 使用辅导员桌面工作台和协同洞察作为当前管理视角，不虚构独立“管理层”角色。
2. 展示部门办理量、逾期数量、高风险数量和报修异议待协调情况。
3. 展示一条从学生提交到后勤结果、学生反馈、辅导员协调的完整时间线。
4. 说明当前是邀请制虚构事务试用，不是学校正式办理入口，也不代表学校制度已批准。

## 反馈回收

每名试用人员完成以下四项：

- 诉求提交是否顺畅：1—5 分
- AI 回答是否有用：1—5 分
- 工单/报修进度是否可见：1—5 分
- 最卡的一步及原话

反馈优先通过页面“试用反馈”提交；网络故障时使用离线反馈表。48 小时内汇总为“问题—复现—负责人—状态—修复版本”。

## H5 兜底

小程序或特定入口不可用时，直接使用同一业务的 H5 地址完成演示。备用链路必须复用同一后端和同一权限，不使用本地 Mock 冒充线上成功。
