## 安装与启动

```powershell
npm.cmd ci
npm.cmd run seed
npm.cmd run dev:api
```

另开终端：

```powershell
npm.cmd run dev:student
npm.cmd run dev:counselor
npm.cmd run dev:logistics
```

记录每个端口首次打开结果、控制台错误和接口失败。

## 必测流程

- 学生登录并提交一条虚构报修。
- 后勤领取原单并提交一次结果。
- 学生提交一次异议。
- 后勤补充说明。
- 辅导员查看双方记录并协调结案。
- 关闭 API 并重新启动，确认原工单、报修和反馈仍在。
- 打开 390px 学生页面和 1366px 辅导员页面，确认无横向溢出。
