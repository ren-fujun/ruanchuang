## D1 验收

状态链：

```text
待后勤分配 → 处理中 → 待学生反馈
  ├─ 满意 → 已修复并确认（终态）
  └─ 一次异议 → 异议待后勤回应 → 待辅导员协调
      → 协调结案（终态）
```

已验证：

- 学生直达后勤，不创建辅导员前置审核。
- 责任范围和异地后勤隔离。
- 两人并发领取只成功一次。
- 一次处置结果后锁定，重复结果返回 409。
- 学生只能提交一次异议。
- 后勤一次回应后交辅导员协调。
- 满意与协调结案均为终态。
- 新报修使用旧 reopen/redispatch 返回 404。
- 截止后无回应可由辅导员协调，并保留 `responseOverdue`。
